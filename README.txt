DRIVER TRANSPORT – BOSS DEMO PWA

This is a Progressive Web App prototype.

For true "Add to Home screen" / standalone app behaviour on Android, the files need to be hosted from an HTTPS web address. Opening index.html directly from a downloaded file will NOT give the full PWA installation experience.

The prototype includes:
- Driver home screen
- Vehicle selection demo
- Walk-around: unit / unit + trailer / trailer only
- YES / NO checks and defect recording
- Allocated jobs with LIVE / PENDING / COMPLETED
- Planner dispatch demonstration
- Trailer last-location demonstration

The checklist wording is placeholder wording until the exact questions from the current work app are supplied.
